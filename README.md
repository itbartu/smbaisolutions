# SMB AI Solutions website

Five-page static marketing website for `smbaisolutions.com`.

## Pages
- `index.html` — landing page
- `how-it-works.html` — process
- `pricing.html` — pricing and domain education
- `about.html` — company introduction
- `contact.html` — email-based contact form

## Launch
1. Open `index.html` locally to preview.
2. Upload all files (except `build.py` and `shared.sh`) to your static web host.
3. Point `smbaisolutions.com` to the host using your registrar's DNS records. Follow that host's exact instructions.
4. Set up `hello@smbaisolutions.com` before publishing. This is a placeholder address, not a configured mailbox.
5. Replace the example construction image (served from Unsplash) with an image you have permission to use and host locally if desired.
6. Replace the email-based form with a real form backend (e.g. Formspree/Netlify Forms), including spam protection and privacy disclosures.
7. Confirm launch pricing and contractual language before taking payments.

No payments, domains, subscriptions, lead scraping or backend automation are implemented yet.
